## 这是什么

飞书里的销售汇总机器人。把 Excel 或飞书表格发给它，回复「汇总」，会生成一份**签约汇总** Excel 发回来。

- 没有网页后台，没有数据库。
- **只汇总签约，回款不做。**
- 群聊必须 **@机器人**；只 @所有人无效。
- 每个人的云表和文件互不影响（按「当前聊天 + 发送人」隔离）。

---

## 怎么用

私聊直接发；群聊写成 `@机器人 命令`。

| 命令 | 作用 |
| --- | --- |
| 上传 `.xlsx` 或发表格链接 | 加入本次临时汇总 |
| `添加云表 <链接>` | 长期登记，以后每次汇总自动刷新 |
| `云表列表` / `云表排序 3 1 2` / `移除云表 2` | 查看、重排、删除固定云表 |
| `汇总状态` | 看当前有哪些来源 |
| `汇总` | 生成并发回 Excel |
| `清空汇总` | 只清临时文件 |
| `清空云表` | 只清固定云表（无确认） |
| `清空下载缓存` | 管理员清本地旧文件 |

推荐：先 `添加云表`，再 `汇总`。之后改飞书原表，再发一次 `汇总` 即可。

完整命令示例见 [飞书机器人完整对话指令规范.md](../飞书机器人完整对话指令规范.md)。

## 怎么运行

**日常使用（推荐）：** 解压便携包，双击「启动机器人.cmd」。关掉用「停止机器人.cmd」。电脑重启后要再点一次启动。

**改代码：** Python 3.11，复制 `.env.example` 为 `.env`，填写 App ID / Secret 和模板路径，然后：

```powershell
.venv\Scripts\python.exe feishu_bot_listener.py
.venv\Scripts\python.exe -m pytest
```

重新打包：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\packaging\windows\build_portable.ps1
```

同一目录不要开两个机器人。`.env` 和 `release/` 不要提交 Git、不要放网盘。

## 权限和配置

`.env` 里三件必填：`FEISHU_APP_ID`、`FEISHU_APP_SECRET`、`FEISHU_SALES_TEMPLATE_PATH`。

导出 Wiki/Sheets 需要开放平台权限 **和** 把应用加入对应文档/知识库，两层都要有。缺节点权限时，机器人会提示把应用加进去。

## 常见问题

| 情况 | 处理 |
| --- | --- |
| 群里没反应 | 是否直接 @ 了机器人 |
| Wiki 没权限 | 应用是否已加入该知识库/文档 |
| 文件下了但不汇总 | 必须是符合 SOP 的 `.xlsx` |
| 汇总失败 | 任一份固定云表刷新失败都会整单停，不会用旧缓存 |
| 公式看起来是空的 | 用 Excel/WPS 打开让它重算 |
| 启动说已在运行 | 先停旧实例 |
| 重启电脑后没了 | 再点「启动机器人.cmd」 |
