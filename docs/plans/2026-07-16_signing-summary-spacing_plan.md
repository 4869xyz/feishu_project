# 签约汇总区块空行实施记录

状态：已完成  
日期：2026-07-16

## 目标

在个人、小组和部门统计层级之间增加清晰的空行分隔，同时保持明细、公式、合并区域和现有人员/组别间距规则稳定。

## 已实施规则

- 每个小组最后一名人员的“个人年度合计”与“小组月度合计”之间固定增加一行。
- 最后一个“小组年度合计”与“部门月度合计”之间固定增加一行。
- 明细与个人月度合计保持相邻；人员之间和不同小组之间原有的一行空白保持不变。
- 两类新增空行分别复用模板的人员间和组别间空行样式，不写值或公式，并设置为非隐藏。
- A 列小组合并区域包含个人与小组之间的空行，但不包含小组与部门之间的空行。

## 验收

- 单组、多组和多人布局均不存在缺失或连续双空行，公式及控制总额不变。
- 两组回归样例的部门汇总移动到第 24–26 行，个人/小组/部门边界及 A 列合并范围正确。
- 完整离线测试 88 项通过，并完成 Python 语法检查、真实模板 XLSX 重开和差异检查。
