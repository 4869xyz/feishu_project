**状态：** 已完成

**负责人：** Agent

## 1. 背景与目标

- 业务背景：用户 Word 含表格与图片，需要原样进入汇总周报。
- 目标：提交的 `.docx` 持久化，生成时嵌入表格与内嵌图片；不对图片 OCR。
- 成功标准：含表格+图片的测试文档生成后，输出 Word 含对应表格单元格与图片关系。

## 2. 范围

**包含：** DOCX 持久化、富文本注入生成、仅媒体 Word 可提交、清理与文档  
**不包含：** 独立图片改嵌入、PDF 图片、复杂浮动版式 100% 还原

## 3. 技术决策

- 源文件路径写入已有 `formatted_content`，避免 SQLite 迁列
- 现有模板占位符仍是 `{{ key }}`，不用 `{{p key}}` / Subdoc（会嵌进 `w:t`）
- 生成时先写入唯一标记，再把合成 DOCX 正文（含图片关系重映射）注入标记段落位置
