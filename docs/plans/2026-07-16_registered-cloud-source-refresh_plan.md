# 固定云表汇总时刷新实施计划

**状态：** 已完成  
**创建日期：** 2026-07-16  
**负责人：** Codex

## 1. 背景与目标

- 当前链接只在消息到达时导出为 XLSX 快照，云表后续编辑不会更新本地批次。
- 允许发送人长期登记十多个固定云表，在执行“汇总”时顺序重新导出并生成新的汇总 XLSX。
- 登记来源跨汇总保留；临时附件仍按批次处理；任一固定来源刷新或校验失败时不使用旧缓存。

## 2. 范围与决策

- 增加 `添加云表 <链接>`、`云表列表`、`移除云表 <编号>` 命令。
- 固定来源按“会话 + 发送人”隔离；Wiki 每次刷新重新解析真实对象。
- 普通链接继续作为临时来源；成功汇总只清临时批次。
- 不实现定时轮询、编辑事件、revision 增量判断、覆盖同一云表或多人共享来源。

## 3. 预计修改

- `clients.feishu_table_export`：提供按已解析链接导出到指定 latest 路径的接口。
- `services.aggregation_batch_store`：保存、列出、移除固定来源并兼容 v1 状态。
- `feishu_bot_listener.py`：解析固定来源命令并在汇总前刷新。
- `tests/` 与项目文档：补齐迁移、命令、失败策略、使用方式和版本记录。
