# 固定云表数字编号与批量管理实施计划

**状态：** 已完成  
**创建日期：** 2026-07-20  
**负责人：** Codex

## 目标与决策

- 固定云表对外使用按当前位置生成的连续编号 `1…N`，内部稳定 ID 和已有缓存路径不迁移。
- 支持 `移除云表 2`、`云表排序 3 1 2` 和 `清空云表`。
- 排序采用完整编号序列；删除或排序后自动重新编号。
- `清空云表` 直接执行，只影响当前“会话 + 发送人”的固定来源及其 latest 缓存，不影响临时文件。

## 实施结果

- [x] 存储层增加固定来源完整重排和批量清空接口。
- [x] 列表、添加、删除、状态和刷新错误回复改用数字编号，保留旧内部 ID 删除兼容。
- [x] 排序拒绝缺号、重复、非数字和越界输入，失败时不改变原顺序。
- [x] 更新 README、架构、模块说明、测试说明和版本记录。
- [x] 新增离线测试并运行完整测试套件。

## 验收
