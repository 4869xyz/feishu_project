# 签约工作表优先汇总实施记录

状态：已完成  
日期：2026-07-16

## 目标

让签约汇总不再依赖固定 `Sheet1/Sheet2` 结构或回款数据质量。单工作表直接使用；多工作表按签约名称优先级选表；回款当前完全跳过并原样保留模板内容。

## 已实施规则

- 单工作表直接作为签约表，仍执行 A:T 表头和金额校验。
- 多工作表依次匹配精确 `签约情况`、精确 `签约数据`、包含“签约+情况”、包含“签约+数据”；同级取工作簿顺序第一项。
- 未找到候选时拒绝文件并列出现有工作表。
- 源回款表不读取、不校验；模板回款表不清空、不修改，缺失也不影响签约。
- 飞书上传回复显示实际签约工作表和明细数，完成回复只显示签约统计。

## 验收

- 覆盖单工作表任意名称、多候选优先级、模糊匹配、无候选拒绝、损坏回款忽略、模板无回款表、模板回款原样保留和签约错误定位。
- 完整离线测试基线为 68 项通过；同时执行 Python 语法检查、XLSX 完整性检查和签约结果可视验证。
