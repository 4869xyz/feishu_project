# 下载缓存安全清理

状态：已完成  
日期：2026-07-16

## 目标与范围

为飞书机器人增加管理员命令 `清空下载缓存`，删除不再参与活动汇总批次的本地下载和历史结果，控制项目运行目录体积。清理范围固定为 `data/inbox/`、`data/archive/` 和 `data/aggregation/output/`。

## 安全决策

- 只有 `FEISHU_CACHE_ADMIN_OPEN_IDS` 中的飞书用户可以执行；未配置时禁用。
- 执行前读取全部批次状态，而不是只保护命令发送人的批次。
- 活动源文件、显式配置的汇总模板和 `.gitkeep` 永不作为删除目标。
- 不扫描 `data/aggregation/state/`，避免破坏批次、上传顺序和来源幂等记录。
- 清理与下载、汇总共用异步锁；单文件删除失败采用尽力执行并报告失败数。
- 文件解析后的真实路径必须仍位于配置的缓存根目录内，越界路径跳过并记为失败。
