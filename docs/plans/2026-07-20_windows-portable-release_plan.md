# Windows 单人免安装便携交付实施计划

**状态：** 已完成  
**创建日期：** 2026-07-20  
**负责人：** Codex

## 1. 背景与目标

- 业务背景：机器人迁移到唯一使用者的 Windows 电脑，使用者只通过飞书操作，不承担 Python 环境配置。
- 目标：生成保存在项目内、可重复更新的免安装发布包，解压后双击即可后台运行。
- 成功标准：目标电脑不需要 Python；当前 `.env` 和模板原样可用；具备中文启动、停止和日志入口。

## 2. 范围

**包含：** Windows x64 `onedir` 打包、冻结路径解析、启动器、构建与交付文档、项目内 `release/` 产物。  
**不包含：** Web/桌面业务 UI、自动开机启动、历史 `data/` 迁移、飞书应用配置变更。

## 3. 影响分析与技术决策

- 受影响模块：运行配置根目录、Windows 工程构建、项目文档和配置测试。
- 数据安全：发布包包含当前 `.env` 和 App Secret，`release/` 必须被 Git 忽略并通过私有渠道交付。
- 技术决策：采用 PyInstaller `onedir`；只收集实际使用的 `lark_channel`，不携带未引用的完整 `lark_oapi`。
- 待确认项：无。
