# 签约明细保留源字体颜色实施记录

状态：已完成  
日期：2026-07-16

## 目标

签约明细 A:T 逐单元格保留源表字体颜色，同时确保字体名称、字号、粗体、填充、边框、对齐、行高和数字格式继续由汇总模板统一提供。

## 已实施规则

- 解析有效签约明细时保存 A:T 的 RGB、主题色、索引色、自动色及 tint。
- 输出明细先应用模板完整样式，再仅替换字体颜色；不复制源字体的其他属性或背景填充。
- A 列组别由空值继承时，同步继承最近一次非空组别单元格的字体颜色。
- 个人、小组、部门汇总行及空行完全使用模板颜色。
- 条件格式产生的动态显示颜色不在本次处理范围内。
- 保留非目标签约工作表时同步维护共享字符串部件及工作簿关系，确保真实模板结果可重新打开。

## 验收

- 覆盖同一行逐格多色、不同来源同内容异色、RGB/主题/索引/自动颜色与 tint、组别颜色继承、汇总行模板颜色和其他模板样式隔离。
- 使用现有固定云表缓存生成临时结果，20 条有效明细、控制总额 3,723,000 元；抽查 A4、B4、C4、D4、I4 的源/目标颜色一致。
- 完整离线测试 88 项通过，并完成 Python 语法检查、真实模板 XLSX 重开和差异检查。
