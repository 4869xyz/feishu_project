# 周例会纪要机器人 · 用户说明

仅支持**私聊**本机器人。周期按上海时区，每周一 00:00 切换到新一周。

## 怎么提交

任选一种发送即可（都会**追加**到你本周纪要）：

- 直接发文字
- 发图片（自动识别文字）
- 发文字型 PDF / Word（`.docx`，表格与内嵌图片会原样进周报）/ Markdown（`.md`）

## 常用指令（原样发送）

| 指令 | 作用 |
| --- | --- |
| `查看我的纪要` | 看本周已提交内容 |
| `撤回本周提交` | 清空本周有效内容 |
| `替换：完整新内容` | 用新内容整体替换本周纪要 |

## 注意

1. 首次使用须由管理员完成账号绑定；未绑定或已停用无法提交。
2. 不支持：群聊、扫描版 PDF、旧版 `.doc`。单独发的图片仍走文字识别；Word 内的图片会原样嵌入周报。
3. 单条内容过长或附件过大时会被拒绝，请拆分后再发。
4. 周日 17:00 / 20:00 若仍未提交，会收到私聊提醒；提交后不再提醒。
